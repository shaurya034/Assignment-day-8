# CSS Grid Gallery and Dashboard

This project demonstrates CSS Grid and Flexbox by building a responsive photo gallery, a magazine-style layout, and a product dashboard.

## Project features

- Responsive photo gallery using CSS Grid
- Gallery columns made with `repeat()`, `minmax()`, and `auto-fit`
- Magazine layout using named grid areas
- Dashboard with a header, sidebar, and product grid
- Product cards arranged with Flexbox
- Layout adjustments for smaller screens

├── index.html
└── README.md
```

## Create a GitHub repository

1. Go to [GitHub](https://github.com) and sign in. If you do not have an account, select **Sign up** and follow the instructions.
2. Click the **+** icon in the top-right corner, then select **New repository**. You can also go to [https://github.com/new](https://github.com/new).
3. Enter a repository name using the format required by your teacher. Example:

   `rollno-firstname-webdev-day08-grid-gallery-dashboard`

4. Add a short description, such as: `CSS Grid gallery and dashboard assignment`.
5. Choose **Public** or **Private**, according to your teacher's instructions.
6. Select **Add a README file** if you are creating the repository before adding your project files.
7. Click **Create repository**.
8. Add your `index.html` file to the repository. You can upload it on GitHub by selecting **Add file → Upload files**.
9. Your `README.md` is already in the repository if you selected **Add a README file**. Otherwise, create and upload one.
10. Copy the repository URL from GitHub. You will need it when sharing your project or uploading files with Git.
